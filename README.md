# AI Resume & Interview Coach

An AI-powered career assistant that analyzes resumes, evaluates ATS compatibility, generates interview questions, suggests resume improvements, and creates tailored cover letters.

## Features

* Resume PDF Upload
* Resume Parsing
* ATS Analysis
* Job Description Matching
* Interview Question Generation
* Resume Improvement Suggestions
* Cover Letter Generator
* Quick Analysis Mode
* Expert Multi-Agent Analysis Mode
* PDF Report Export

## Tech Stack

* Python
* Streamlit
* Groq API
* Octochains
* PyPDF
* ReportLab

## How It Works

1. Upload Resume PDF
2. Paste Job Description
3. Choose Analysis Mode
4. Generate AI Career Report
5. Download PDF Report
